    How it works

    Every input is measured first, then the pipeline adapts to it.

    1. 1

      Measure

      Noise level, fraction of missing samples, and how much colour texture has no matching depth edge.

    2. 2

      Classical

      Denoise, fill large holes, joint bilateral upsampling and a guided filter, tuned from the measurements.

    3. 3

      Learn

      A 0.5 M-parameter CNN predicts a residual. A learned gate decides how much colour to trust.

    4. 4

      Combine

      The hybrid picks and fuses paths per image, so it is never blindly trusting one estimator.

    Results

    Measured on unseen NYU Depth V2 test images (never used for training or tuning). Lower RMSE is better.
